# e-plantShopping

## Overview

**e-plantShopping** is a React and Redux plant shopping application for the
Paradise Nursery storefront. It lets users browse houseplants in categories
such as air-purifying, aromatic, insect-repellent, medicinal, and low-maintenance
plants, and add products to a shopping cart.

## Features

- Browse plants by category
- View plant descriptions and prices
- Add plants to the shopping cart
- Manage cart items
- Responsive storefront interface

## Technologies

- React
- Redux Toolkit
- React Redux
- Vite
- CSS

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```
